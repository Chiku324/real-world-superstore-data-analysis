This project presents a complete real-world dataset analysis using the Sample Superstore transactional sales dataset. The objective is to convert raw order-level data into meaningful business insights related to sales, profitability, products, categories, regions, customer segments, discounts, and time trends. The project follows a structured data analyst workflow: dataset selection, data inspection, quality checking, preprocessing, exploratory data analysis, KPI calculation, visualization, interpretation, and recommendation.

The analysis begins by checking the dataset structure, data types, missing values, duplicate records, and date fields. Order Date and Ship Date are converted into proper datetime formats, while derived metrics such as Order Month, Order Year, and Profit Margin are created for deeper analysis. Key performance indicators include total sales, total profit, profit margin, quantity sold, unique orders, customers, and products.

The project uses Python with Pandas, NumPy, Matplotlib, and Seaborn. Visualizations are created for monthly sales trends, sales by category, sales by region, profit by sub-category, and the relationship between discount and profit. The analysis emphasizes that high revenue does not always mean high profitability and that discount decisions should be evaluated together with profit margin.

The final deliverables include a professional report, reproducible Python script, Jupyter Notebook, README documentation, dataset reference, KPI output, and charts. The project also includes limitations and future improvements such as adding return data, inventory cost, shipping cost, marketing spend, customer lifetime value, and interactive dashboarding.

This project demonstrates practical skills in data cleaning, exploratory data analysis, visualization, business reasoning, and communicating findings clearly. It is designed as an internship-ready portfolio project and can be reproduced by placing the full dataset in the specified data folder and running the analysis script.
